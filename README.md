# Market Basket Analysis

A data analytics project focused on discovering **product associations and purchasing patterns** from transaction data.

## Objective

Market Basket Analysis helps answer questions such as:

- Which products are frequently purchased together?
- Which combinations could support cross-selling opportunities?
- What patterns can inform promotions or product placement?
- Which purchasing relationships are strong enough to be actionable?

## Analysis Workflow

1. Prepare and clean transaction-level data
2. Explore product frequency and basket composition
3. Identify recurring product combinations
4. Evaluate association patterns
5. Translate results into business-oriented insights
